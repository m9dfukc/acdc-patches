AC/DC Patch Loader

Load OWL patches into a Befaco / Rebel Technology AC/DC over USB MIDI, right from the browser: run one from RAM or store it in a slot. Runs in Chromium-based browsers (Chrome, Edge, Brave, Opera) on desktop; Firefox only with a site permission, Safari not at all. Part of acdc-patches.

Activate sends a program change: the patch runs until the next power cycle, nothing is stored. The ↓ buttons download a slot as a backup. Erase deletes one slot after downloading it as a backup; the other slots keep their numbers.

Log

    Good to know

    • Only tested with the AC/DC, on the firmware fork v22.4.r-fx9a. The protocol is the one of all OpenWare devices, but other devices were never tried.
    • The page sends only: patch upload, run, store, erase of a single slot (1–39), slot download, read-only requests and program changes. It cannot erase the whole storage or touch resources, settings, firmware or the bootloader.
    • Before a slot is overwritten or erased, the page downloads it and offers it as a .syx file. The download is checked against the size and CRC the device reports. On the official firmware, downloads while a patch runs can arrive damaged, and in rare cases the device stops sending MIDI until a power cycle. If a backup fails, nothing is changed.
    • Close other pages that talk to the device (the OWL patch library pages poll it) and pick the patch before an app opens the AC/DC's audio stream: on some firmware a patch change during streaming breaks playback until the stream restarts.
    • The page checks a file's header (magic, link address, size) before the upload, the firmware checks it again. A patch built for another OWL platform can still load and misbehave: use files made for your device.
    • No data leaves your computer: the page has no server part, MIDI goes straight from the browser to the device.
